How to judge

The question is not whether the two pictures match pixel for pixel. It is: would you accept these as the same character in the same film? Hover any pair to compare them large.

keep
You would use this. It reads as them.
close
Recognisably them, but something specific is off — wrong hairstyle, wrong age, wrong costume. The identity landed and a detail did not. This is the answer for "close but not exact", and it is the most useful verdict on the page: it says the method works and the card needs a better tag.
not them
A different person. Different bone structure, different colouring, nothing you could cut together with the reference.

What if the style is different — photoreal reference, anime render? That is not an identity failure. Judge the things that survive a change of medium: hair colour, eye colour, build, age, scars, glasses, distinguishing marks. A style change is the pipeline doing what it was asked; a change of person is not. (Every reference in this set happens to be illustration, so it should not come up here.)

What if you genuinely cannot tell? Leave it. An unjudged sample is counted honestly as "not looked at" and costs nothing. A guess is worse than a gap — it puts a number under a verdict that nobody actually made. If several are unjudgeable for the same reason, that is worth telling me: it usually means the reference is bad, not that you are.
