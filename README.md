# comfy-studio — an offline film studio on one RTX 5090

Everything runs on this box (`k4shix`, 192.168.0.45, Fedora, RTX 5090 32 GB) with open
weights: pictures, video with sound, speech, music, 3D, and the measurement that decides what
is kept. Nothing is paid for by default; the two paid doors (Seedance, Nano Banana) are wired
and switched off (playbook §96.4).

*Rewritten 2026-09-27. The previous README (2026-07-29) described the first kit; that history is
in `docs/STATE.md`. This file is the map; `ARCHITECTURE.md` is the constitution.*

## Three ways in

| you want | open | it runs |
|---|---|---|
| **make a film with no AI knowledge** | http://192.168.0.45:8777/start | the app: characters → places → film editor, every step measured |
| **make a sequence the way the paid breakdowns do** (refs → start frames → shots → picks → finish), hands on | http://192.168.0.45:8777/shots - shots & specs: the spec sheet (what each shot must keep, locked when done) and the shot editor (models, seeds, start frames, takes, picks, trims, a Seedance suggestion) on one page; /specs opens the same page | `studio/_tools/fight.py` on a shot script in `studio/shotscripts/`, the same tools the 2026-09-29 demo films were made with |
| **drive an engine directly** | the shell | `python3 scripts/comfy.py run workflows/<file>.json -s node.inputs.key=value` |

The runbook for the second way is `craft/ACTION_SEQUENCE.md`; the book for a person with no AI
knowledge is `docs/METHOD.md` (`studio/samples/docs/METHOD.pdf`).

## The rules, in one breath

Refs before words; never describe what a picture carries; one anchor per scene; one beat per
shot when a face matters; the word *cut* makes the cut; sound is written; the plate is the
place; the finish is half the film; nothing is adopted on one render; a take is picked iff its
fault list is empty. The long form is `docs/METHOD.md`; the numbers behind each rule are §95.
And one from this month, learned four times over: **when a number says the engine cannot,
check the ruler first** (§98.5b, §98.6, the crouch, the 2026-09-07 ref2va wiring).

## Keeping current

`python3 studio/_tools/review_clock.py` says whether the fortnightly review (§0) is due and
lists orphan weights; `python3 studio/_tools/inventory.py` lists the shipped templates nobody
has mirrored. The review of 2026-09-27 (§0.2) found Krea 2, Qwen-Image-2.1, Wan Animate 2 and
the Ingredients adapter sitting in the installed template set, two months after they shipped.

## Running it

```bash
bash ~/shared/comfy-studio/scripts/studio.sh          # ComfyUI on :8188 and the app on :8777
python3 studio/_tools/review_clock.py                  # is the review due; what is on disk unused
python3 studio/_tools/fight.py --sequence ash-court --cast --anchors --shots --seeds 11 202 3003
```
